# PMC5304557 Source Notes

- Source URL: https://pmc.ncbi.nlm.nih.gov/articles/PMC5304557/
- PMID: 28210569
- DOI: 10.4322/acr.2016.052
- Title: Infant acute myocarditis mimicking acute myocardial infarction
- Access: PMC article HTML and NCBI EFetch PMC XML.

Blind extraction scope:

- Rankable data came from the CASE REPORT: age/sex, recent rhinorrhea/cough, sudden dyspnea, vitals, respiratory distress sign, ECG findings, chest x-ray, initial labs, early repeat ECG/markers, and echocardiogram findings.
- Record-only data includes treatment, death, autopsy findings, and the autopsy-attributed final diagnosis.

Caveats:

- The case report gives only selected lab values; normal renal function and normal CPK were represented as qualitative observations.
