# First principles

1. **Knowledge-time integrity**: a time cut may contain only evidence available
   by that cut. Later pathology, serology, treatment response, and outcome never
   leak backward.
2. **Observation is not state**: measured facts, inferred disease state,
   clinician hypotheses, and actions remain distinguishable.
3. **No case-driven repair**: the test may expose ontology or geometry defects,
   but it may not tune the atlas to make either expected disease win.
4. **Diagnosis-neutral evidence**: ordinary clinical findings use generic axes;
   paper diagnoses and outcome labels are never ranking inputs.
5. **Dynamic sufficiency must be demonstrated**: a model that can rank each
   frozen snapshot is not thereby a longitudinal state model.
6. **Association is not intervention**: observed improvement after treatment is
   a temporal response unless a causal effect is independently identifiable.
7. **Unsupported mechanisms remain unsupported**: if the active atlas lacks a
   newly emerging process, the correct result is a visible representational gap,
   not forced assignment to the nearest disease.
8. **A pass is end-to-end**: it requires faithful staging, live runtime output,
   correct interpretation, and explicit limits—not merely top-1 agreement.
