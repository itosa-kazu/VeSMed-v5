# 新临床动态地图：真实复杂病例实验计划

## 目标

独立实现并测试用户定义的新框架；本项目不调用、不评价、也不接入
VeSMed V5 runtime。

```text
患者状态 =
    机制／拓扑分支的不确定分布
  + 分支内局部连续坐标
  + 代偿／失代偿等离散运行模式
  + 足以支持当前动作集合的历史摘要
```

因子图负责观察生成，混合受控动力学负责时间/治疗转移，分支/分层
几何负责临床邻近，共享状态同时供诊断、自然预测和治疗预测使用。新
检查或新治疗暴露状态碰撞时，地图应能局部细化。

## 病例

1. PMC10448002：anti-GBM 工作假说到 complement-mediated TMA 的诊断反转，
   同时存在活检出血与多治疗混杂。
2. PMC7005653：HAV 急性肝衰竭过程中 day-2 新发 Takotsubo/cardiogenic
   shock，随后多器官恢复。

## 执行阶段

1. 从原文独立建立 observation/action/hypothesis/outcome 分离的事件账本。
2. 实现不依赖疾病标签硬规则的最小共享状态内核。
3. 逐事件执行 `update -> diagnose -> forecast -> plan`，所有任务读取同一
   state fingerprint。
4. 运行 history/action/mode/factor/topology 消融与负对照。
5. 构造新治疗反应相反的受控 twin pack，检验状态碰撞、拒答、提出新
   检查及局部拆分；该 pack 只测试扩展机制，不冒充真实临床因果证据。
6. 独立审计证据与结论，区分结构可运行、病例内拟合、预测支持与不可
   识别边界。

## 交付物

- 框架形式规格与机器 schema；
- 两个来源可追溯的真实病例事件流；
- 独立最小运行内核及自动测试；
- 全流程结果、消融结果和局部细化结果；
- 中文最终报告。
